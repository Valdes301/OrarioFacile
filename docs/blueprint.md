# **App Name**: OrarioFacile

## Core Features:

- Calendar View: Display the schedule in a daily/weekly calendar view.
- Class Management: Add and edit classes with details such as subject, time, and location.
- Drag and Drop Rescheduling: Reschedule classes by dragging and dropping on the calendar.
- Daily List View: View the daily schedule as a list, with total hours per subject.
- Docker Compose Configuration: Generate docker compose file for openmediavault on raspberry PI 4 for easy deployment.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) to provide a clean and calming aesthetic.
- Background color: Off-white (#F5F5F5) for a soft, neutral background that complements the light blue.
- Accent color: Slightly darker shade of blue (#87CEEB) for interactive elements and highlights, providing visual contrast.
- Body and headline font: 'Inter', a grotesque-style sans-serif, to provide a modern and objective look suitable for schedules and other details.
- Use simple, outline-style icons to represent subjects and actions.
- Clean and spacious layout with intuitive drag-and-drop functionality for easy scheduling.
- Subtle animations and transitions for a smooth and engaging user experience during rescheduling and navigation.
